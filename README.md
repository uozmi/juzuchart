## JuzuChart
フローチャートのエディタです。LLMが自然言語で書かれた手順や業務の流れをフローチャート化します。（予定）

## 背景

業務の流れを文書化するには高い認知コストがかかるため、多くの現場では業務フローがメンバーの頭の中にしか存在しない「属人化」が起きている。
共通認識が曖昧なままだと、メンバー間で認識のズレが生じ、業務フローの改善に取り組むことも難しくなる。

読み手と書き手の双方に、ドキュメントが残らない理由がある。
- **読み手**：全体像を掴むには、ドキュメントを読みながら頭の中で構造を組み立てる必要があり、認知負荷が高い。そもそも文字だけのドキュメントは読まれにくい。
- **書き手**：業務の流れを文書や図に起こす作業コストが高い。

juzuchartは、フローチャート作成の作業コストと、読み取りの認知コストの両方を圧縮し、書き手と読み手の負担を減らすことを目的としている。
最終的には、自然言語で書かれた手順や業務の流れをLLMが解釈し、フローチャートに変換することを目指している。

## 現状
- **フローチャートエディタ**：完成。操作を簡略化し、Excelでフローチャートを作成する場合と比べて作成工数を半分以下に短縮（自作サンプルでの比較）。
- **自然言語 → フローチャート変換**：中間表現（Procedure IR）の出力ロジックを作成中。
